# Multilingual LLM Evaluation Benchmark — EN↔TR

This repository contains a small evaluation benchmark for English↔Turkish translation quality assessment.

What’s included
- rubric.md — Scoring rubric (5-point scale) with fidelity/meaning-drift guidance.
- samples/ — 30 annotated sample files (JSON), one per sample. Fields: id, source, source_lang, reference, hypothesis, hypothesis_lang, score, notes.
- score.py — Simple scorer that loads samples/*.json and produces a CSV summary (samples_summary.csv) and basic stats.
- findings.md — Observations and recommendations from the 30-sample review.
- samples_summary.csv — CSV summary of the current samples (generated by running score.py).

Data provenance and copyright-safety
- All samples in samples/ are synthetic and original: they were authored specifically for this benchmark to avoid reproducing copyrighted text or including realistic personal data.
- A comprehensive copyright-sensitivity sweep was performed across all 30 sample source sentences using web searches (exact and near-exact / n-gram checks). Results:
  - 25/30 samples: no exact or near-exact matches found in public web indices.
  - 3/30 samples: matched common, short boilerplate phrases (e.g., rescheduling or acknowledgement queries) and were rephrased to reduce boilerplate overlap.
  - 1/30 sample: previously contained a hallucinated sensitive value (a fake credit-card number) and was replaced with a non-sensitive synthetic sentence.
- Flagged items were reworded to ensure uniqueness while preserving the phenomena coverage (negation, numbers, named entities, register, technical phrasing).

How to run the scorer

Prerequisites: Python 3.8+.

Run locally:

```bash
python3 score.py
```

This will:
- Load all JSON files in samples/
- Print summary statistics (n, mean, median, stdev, distribution)
- Write samples_summary.csv to the repository root

Note: samples_summary.csv is already generated and reflects the current synthetic dataset. Re-running the scorer will regenerate it from the contents of samples/.
